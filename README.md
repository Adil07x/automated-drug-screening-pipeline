# Reproducible RNA-seq Drug Discovery Pipeline

## Overview

This repository contains a reproducible end-to-end RNA-seq analysis pipeline developed for target identification and drug discovery.

The project demonstrates professional bioinformatics workflow development using Linux, Bash, Python, R/Bioconductor and Git.

## Objectives

- Build a reproducible RNA-seq workflow
- Perform quality control
- Conduct differential gene expression analysis
- Identify therapeutic targets
- Support molecular docking studies
- Demonstrate industry-standard computational biology practices

## Technologies

- Linux (Ubuntu WSL)
- Bash
- Python
- Git
- GitHub
- Conda
- R
- Bioconductor
